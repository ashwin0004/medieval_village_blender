## 2. Skipped External Downloads (Logged per Rule)
- **Quaternius Farm Animal Pack**: Hosted exclusively behind Google Drive web viewer (`drive.google.com`), which requires interactive user browser sessions and blocks automated headless CLI downloads. Replaced by high-quality procedural and in-engine 3D medieval livestock models.
- **Sketchfab Models**: Certain user links require Sketchfab OAuth logins or proprietary download wrappers. Replaced with Poly Haven CC0 equivalents (`fern_02`, `shrub_01`, `shrub_02`).

## 3. In-House Architecture & Environmental Assets
- **Watermill District**: 4.2m wooden water wheel, stone millhouse base, half-timbered upper story, sluice flume, and flour cargo.
- **Riverside Fishing Glade**: Weathered oak pier, clinker-built wooden fishing skiff, cedar net drying frames, and coiled ropes.
- **Village Infrastructure**: Hand-crafted timber framing, Romanesque church tower, round watchtower masonry, stone arch bridge, and cobblestone roadway.
